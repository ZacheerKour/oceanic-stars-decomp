## 2026-10-28 real window sizes and side fill
**The picture is still a centred 4:3 rectangle (scale_mode fit / integer / stretch unchanged); the window can now be any size, and what is outside the picture is filled.**

- **settings.ini.** `window_width` + new `window_height` (360..4320, `0` or absent = the old 4:3 height from `window_width`, so existing files behave as before). `side_fill = off | blur | art` (default `blur`). Invalid values fall back to the default with a `play\settings.warn` note (launcher and `play.ps1` agree; `equiv.ps1` checks it). The launcher passes `PSXRT_WINDOW_HEIGHT` (only when set), `PSXRT_SIDE_FILL`, `PSXRT_SIDEFILL_DIR=play\sidefill`.
- **Window size.** `psxrt_patch` on main.cpp calls `PSXRT_WINDOW_HEIGHT` (`stubs/psxrt_video.h`) after the stock 4:3 clamp: a window larger than the display's usable area shrinks keeping its shape. Borderless fullscreen is unchanged (one row short of the monitor). The F10 size row still offers the five 4:3 widths; choosing one also writes `window_height = 0`.
- **Side fill** (`stubs/psxrt_sidefill.inc`, compiled inside gpu_gl_renderer.c, called at the top of the OSD stage of `gl_swap_with_osd`: after the picture, before the F10 menu / toasts). The picture rect (the same letterbox every present uses) is copied to a texture and one window-sized triangle draws everything outside that rect: `blur` = the copy cover-scaled, 32-tap blurred, 50% brightness; `art` = a random PNG of `play\sidefill\*.png` (one pick per boot, `stubs/psxrt_sidefill.c`, stb_image, max 8192 px) cover-scaled and faded into the blur toward the picture edge (soft vignette). No usable PNG -> blur. Nothing is drawn when the picture fills the window (4:3 window, stretch). The menu box lies inside the 4:3 rect, so fill never sits behind it.
- **Launcher.** Window size list: 1280 x 720, 1920 x 1080, 2560 x 1440, 3440 x 1440 (ultrawide), 3840 x 2160, then Classic 4:3 (960 / 1280 / 1440 / 1920 / 2880 wide). New Side fill dropdown (Off / Blurred game / Game art). Selecting a size writes both keys. `--selftest` covers the mapping, validators and the env lines.
- **Not done.** Per-scene art and crossfade (one random image per boot); a live menu row for side fill.
- **Evidence** (hidden runs of `qs_display_pic.txt`, `PSXRT_WINDOW_AT=12300:<w>x<h>`, `recomp/rtfull/_run/sf_*/win_pic.png`, build `_build_x`): `sf_blur_3440` 3440x1439, picture x 760..2679 (4:3 centred), sides mean G 6.5 / 7.0 vs 0 with `sf_off_3440`; `sf_blur_1080` 1920x1080, picture x 240..1679, sides non-black; `sf_art_3440` with two dummy PNGs (log `art 1600x900`, bright stripes at the sides fading to the blur at the picture edge); `sf_empty_3440` empty folder -> log `no usable PNG ... blur`, same as blur. The captured scene is the dark star-field title, so the blur is dim by nature.
