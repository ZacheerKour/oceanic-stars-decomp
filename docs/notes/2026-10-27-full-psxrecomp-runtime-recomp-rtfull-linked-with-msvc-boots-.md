## 2026-10-27 Full psxrecomp runtime (recomp/rtfull): linked with MSVC, boots to the title menu
**Result: `psxrecomp-game.exe` (psxrecomp f42d2c0 full runtime, 164 runtime TUs + OpenBIOS backend + boot exe C) links with MSVC 14.44 and runs headless to the title screen, no fatal in 21,569 frames (200 s wall, ~1.6x speed).** Evidence: run log `recomp/rtfull/_run/boot_openbios.log` (`[FPS] game: 91.6 fps (1.53x) | frames: 21542`), heartbeat `frame_count 21569, fatal None, i_mask 0x4D`, and VRAM dumps: at ~40 s the Enix logo and "Sony Computer Entertainment America Presents" textures plus a 24-bit (MDEC) display buffer; at ~180 s the title menu textures ("New Game / Continue / Voice Collection", FMV list) beside a 24-bit background. Program A runs in the dirty-RAM interpreter (3.8e9 interpreted instructions; no overlay C linked yet). So the full runtime gets further than our minimal `recomp/rt` (which stops at 0x8003F900): the stall there is an rt-side difference, not a game bug.

**Build** (`recomp/rtfull/`, all output gitignored under `_deps/`, `_build/`, `_run/`; the clone is never written: `git status --porcelain --ignored` empty is checked before and after):
- `build_deps.ps1`: SDL3 3.4.10 (shared DLL) and zlib 1.3.1 (static, `/MT`) from the user's archives in `tools/dl` (sha256 checked against the deps.manifest pins), extracted to `tools/ref-deps/`, CMake+Ninja offline (`FETCHCONTENT_FULLY_DISCONNECTED`). zlib's CMake renames `zconf.h` to `zconf.h.included` in its own extracted source dir.
- `CMakeLists.txt`: source list parsed from the clone's `PSXRECOMP_RUNTIME_SOURCES` block, same defines as `runtime.cmake` for a non-oracle build. Required and not obvious: **`PSX_NATIVE_BUILD=1 PSX_ENABLE_BLOCK_CYCLES=1`** (without them the guest clock stays at 0 and the OpenBIOS kernel spins forever: freeze dump `psx_cycle_count 0`), `/experimental:c11atomics` for C, `/STACK:64MB`, static CRT. `overlay_codegen_hash.h`, the BIOS registry and the execution profile header are generated into the build dir.
- Copy-with-patch (edited copies in `_build/patched/`, each edit must match once): `main.cpp` static_assert on two constexpr locals inside a lambda (MSVC C2131; the flags are constexpr false); `gpu_gl_renderer.c` unguarded `__atomic_*` -> `_Interlocked*`.
- Stubs: `libchdr` headers + failing `chd_*` (CHD off), `texture_image_decode` (no libwebp; HD packs off).

**Risky features cut:**
- Netplay/lobby: `PSX_NETPLAY` path not built (no recomp-net, no `rnet_ws`), `PSX_HAS_LOBBY_CLIENT` undefined. Debug TCP server: `PSX_NO_DEBUG_TOOLS=1`, and `mips_decoder`/`disasm_shim` left out.
- `stubs/sandbox_stubs.c` defines the `__imp_` import pointers, so the linker never pulls these from the import libs for any code in the exe (runtime and static CRT, whose `system`/`_popen` end in `CreateProcessW`): `CreateProcessA/W`, `ShellExecute*`, `WinExec` fail; `LoadLibraryA/W/ExA` fail (overlay DLL cache, BIOS modules); `LoadLibraryExW` is allowed only for a bare name with `LOAD_LIBRARY_SEARCH_SYSTEM32` (bcrypt.dll for SHA-256, CRT thunks); every Winsock call and `GetAdaptersAddresses` fails (so `api.ipify.org`, LAN discovery and UDP bind cannot reach the network); ws2_32/iphlpapi/wsock32/wininet/winhttp are `/NODEFAULTLIB`. Each block prints `[psxrt-sandbox] blocked ...`; none fired in the runs.
- `build.ps1` audits the import table after every link: `import audit OK: 7 DLLs` = SDL3, dbghelp, COMDLG32, OPENGL32, SHELL32, bcrypt, KERNEL32; no blocked DLL or function. SDL3.dll keeps its own imports (needed for GL/audio/input later).

**Run** (`run.ps1`: `--headless --no-launcher --game _run/game.toml`; `PSX_FPS_TELEMETRY=1` for frame counts, `PSXRT_VRAM_DUMP_SEC=n` for VRAM PPMs from `stubs/psxrt_diag.c`). The runtime writes only beside the exe/run dir: `card1/2.mcd`, `cache/SCUS-94421/`, `mods/state.toml`, `bios.cfg`, `.pst_bios_isolated`, freeze heartbeat/dump JSONs.

**BIOS:** only OpenBIOS is linked (its generated C ships in the clone). `--bios roms/scph5501.bin` falls back to OpenBIOS silently: SCPH-5501 is a "known image" whose backend the runtime would build at run time (python + gcc/tcc + LoadLibrary), which is both absent and blocked. To use the user's BIOS, generate `SCPH5501_full.c/_dispatch.c` ahead of time with `psxrecomp-bios --config bios/SCPH5501.toml` (not audited: `main_bios.cpp` runs `std::system` for a `cl /c` self-check) and link it as a second stem (+ `PSX_SHELLWIN_INTERP_DEFAULT=1`, the profile says the 5501 shell runs interpreted).
