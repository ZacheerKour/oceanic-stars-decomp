## 2026-10-27 graphics options
**The pause menu (F10 / Select+Start) has a Graphics options page; every change is live where the runtime allows and is written back to `settings.ini`.** Build `_build_gfx` (OpenBIOS, `SDL_AUDIODRIVER=dummy`, hidden window, scripts `recomp/rtfull/input/qs_gfx_menu.txt`, `qs_gfx_mode.txt`, `qs_gfx_hint.txt`).

- **Rows.** Window mode (windowed / borderless fullscreen), window size (640, 960, 1440, 1920, 2880 wide = 480p..2160p, 4:3), scale mode (fit / integer / stretch), filter (linear / nearest), internal resolution (1x..8x), scanlines (F4 also toggles). Left/Right or Cross/Enter changes, Esc/Circle goes back. Widescreen is not offered: the picture is 4:3 and the runtime has no honest widescreen for this game.
- **Live evidence** (log line `[psxrt-gfx]` per change, `_run/gfx*/`): window 960 -> 1440 (`win_after_integer_nearest_s.png` is 1440x1080, integer picture 1280x960 at x 80..1359); scale mode and filter (capture differs from `win_before.png`); internal resolution 1x -> 2x applied live (`scale 2`, no RESTART tag); scanlines on; borderless fullscreen on and off in a hidden window (`fullscreen 1`, window 3440 wide, then back to the chosen 1440).
- **settings.ini.** Only the changed value is rewritten (last matching line wins, comments, other keys and line ends stay; temp file + replace). `diff` against `settings.default.ini` after the script shows exactly `window_width, render_scale, scale_mode, filter, scanlines`. Values are validated before writing with the ranges `play.c` uses (`window_width` 640..7680). `PLAYTHISGAME.exe --selftest` and `equiv.ps1` (`gfx_menu_written`) accept a menu-written file with no warning. New keys: `scanlines`, `window_mode`, `hint_shown`.
- **First-start hint.** Toast "F10 or Select+Start = menu (Graphics options inside)" at about 5 s (`win_hint_toast.png`), then `hint_shown = 1` is added.
- **After restart only.** `window_mode` (the game starts in the saved mode), and `render_scale` if the renderer refuses the live change (the row then says RESTART; this path was not triggered in the test).
- **Not verified.** Navigation by a real keyboard or pad press (the script drives the menu in-frame; the stock key/pad mapping to menu inputs is unchanged), a visible fullscreen toggle on a real monitor, a 4K window, feel and 60 fps with 4x+ on real hardware, the RESTART path.
