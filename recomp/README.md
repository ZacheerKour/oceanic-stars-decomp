## First run on Windows (exact steps; none of this was executed when writing it)
1. **Toolchain** (per psxrecomp `docs/GETTING_STARTED.md`): Git, Python 3.11+, and either the `cmake-clang-v1` toolchain ZIP from RetroPorting-Toolchains
   or MSYS2 MinGW-w64 / MSVC. SDL3 is fetched automatically. Expect a multi-GB install.
   **BIOS (decided 2026-10-27, RECOMP_NOTES '2026-10-27 BIOS usage'):** the game runs on your own retail SCPH-5501 dump, not OpenBIOS (`game.toml` sets
   `openbios = false`). In the title project: copy the dump to `psxrecompios\SCPH5501.BIN` (gitignored; sha256 must equal the profile pin),
   `git -C psxrecomp apply ..\<this repo>ecompios\SCPH5501_install_slots.patch`, `bash psxrecomp/tools/regen_bios.sh --config bios/SCPH5501.toml`,
   configure with `-DPSXRECOMP_BIOS_STEMS=OpenBIOS;SCPH5501 -DPSX_SHELLWIN_INTERP=ON`, and at run time pass `--bios <path>\SCPH5501.BIN` once
   (remembered in `bios.cfg`) or leave `SCPH5501.BIN` in `bios\` next to the exe for first-run discovery.
2. **Private title repo** (do not put game-derived output in this public repo): make a sibling folder, add psxrecomp as a submodule pinned to a SHA
   (reference clone was at f42d2c0), then scaffold:
   `powershell -File psxrecomp\tools\new_project_layout\setup_project.ps1 -Disc "<your Disc 1>.cue" -Dir <title-dir> -Name SO2 -Yes -NoNetplay -NoGithub`
   (known upstream bug: issue #387, "Try statement is missing its Catch or Finally block").
3. Put your two `.cue/.bin` under `disc\` and copy `recomp\game.toml` over the generated one, `config\seeds.txt` to `seeds\seeds.txt`, `config\symbols.toml` to the root.
   Resolve every `TODO(verify)`: run `python psxrecomp\psxrecomp_cli.py verify-disc` and fill the `prepare_disc` digests and serials from its output.
4. **Boot exe only first** (cheap, static): `python psxrecomp\psxrecomp_cli.py analyze --config game.toml --emit-symbol-addrs --emit-tsv`
   and compare function boundaries to our 29 matched functions (they live in the main overlay at 0x8002f810, not in the exe, so compare against the exe's own
   functions / our seeds instead). This builds `psxrecomp-analyze` (a C++ build); that is why it was not run here.
5. `python psxrecomp\psxrecomp_cli.py generate` (boot exe only: leave `aot/overlays.json` out for now). Expect a runnable-looking boot exe that loads
   `SO2.BIN`, then dies or hangs.
6. **What we expect to fail first**: the game's code is in SLZ-compressed overlays inside the encrypted-TOC archive `SO2.BIN`, and psxrecomp has no SLZ/TOC extractor
   (`prepared_files` supports only `bpe_container`; no method in `aot_overlay_pipeline.py` fits). The boot exe loads entry 1 (main program A) and jumps to it, so the first
   run reaches uncompiled RAM and falls to the interpreter (slow) or aborts on the unknown overlay. Fix path (decided 2026-10-26, RECOMP_NOTES.md '2026-10-26 SLZ overlays into the AOT pipeline'): register the `so2_slz` decoder in `prepared_files.py` and run
   `aot_overlay_pipeline.py extract` with `aot/overlays.json` and `--disc` disc 1. Rejected alternatives: (a) write our own `overlay_captures.json` (schema v3) from
   our extractors and feed `compile_overlays.py --captures` (accepts disc-derived records; needs `dispatch_entry_pcs` per overlay, unverified), (b) fork
   `aot_overlay_pipeline.py` with an `slz_members` method (port `analysis\toc.py`, `analysis\slz.py`; spec in `docs/SLZ.md`, `docs/SO2BIN_TOC.md`; keep the fork out of this repo, licence), (c) upstream it.
7. Then: run with the interpreter and overlay capture enabled to find indirect targets (checklist step 6 in RECOMP_NOTES.md).
