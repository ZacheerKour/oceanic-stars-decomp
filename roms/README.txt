PUT YOUR STAR OCEAN: THE SECOND STORY (USA) DISCS HERE
=======================================================
Copy your own two disc images into this folder (roms\), then double-click INSTALL.bat in the folder above.
Nothing from this folder is ever uploaded or committed.

You need BOTH discs of the USA release (SCUS-94421 = disc 1, SCUS-94422 = disc 2), any file names, any order.
Accepted formats, directly in this folder (not in sub-folders):
  .7z or .zip   an archive holding the disc (.bin, or .bin plus .cue)
  .bin          the raw 2352-byte disc image (a .cue next to it is fine, it is used to find the .bin)
  .cue          a single-file cue sheet (one .bin per disc)
  .chd          needs chdman.exe (part of MAME) on PATH
NOT accepted: .iso (2048-byte), other regions, modified images.

Optional BIOS: your own SCPH-5501 dump saved here as scph5501.bin. Without it the open-source OpenBIOS is used.

If nothing is found, INSTALL.bat tells you so and opens a file picker; you can also drag the disc files onto INSTALL.bat.
The installer copies the verified discs into roms\disc1 and roms\disc2; your original files are left alone.
